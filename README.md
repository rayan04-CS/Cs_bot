# 🎓 Computer Science Student Bot

بوت تلغرام — مكتبة قسم علوم الحاسوب. نفس فكرة الموقع: فصول → مواد → (شيتات / أسئلة / مراجع) → ملفات، وأنت الأدمن تضيف وتحذف وتنقل المواد من داخل تلغرام نفسه.

## الملفات
| الملف | وظيفته |
|---|---|
| `bot.py` | كود البوت كامل |
| `courses.json` | قائمة المواد (39 مادة) مع الفصل والوحدات والنوع |
| `content.json` | الملفات المضافة لكل مادة (يبدأ فاضي، والبوت يعدّله بنفسه) |
| `assets/tree.jpg` | صورة شجرة المواد اللي تطلع بزر 🌳 |
| `requirements.txt` | المكتبة المطلوبة |

## 1) اعمل البوت في تلغرام
1. افتح تلغرام وكلّم **@BotFather**.
2. اكتب `/newbot` واتبع التعليمات (اسم ثم username ينتهي بـ bot).
3. يعطيك **توكن** شكله تقريباً `123456:ABC-xyz...`. احتفظ فيه.
4. كلّم البوت الجديد واكتب `/start` مرة وحدة، ثم اكتب `/myid` — بيردلك ما يفهمها إلا بعد ما نشغّله، فخليها لين تشغّله.

## 2) ارفع الكود على GitHub
1. اعمل حساب على github.com إذا ما عندك.
2. اضغط **+** ثم **New repository**، سمّه مثلاً `cs-student-bot`، خليه **Public** أو **Private**، واضغط **Create repository**.
3. اضغط **uploading an existing file** وارفع كل الملفات اللي في هذا المجلد (بما فيها مجلد `assets`).
4. اضغط **Commit changes**.

## 3) شغّل البوت على Railway (مجاني ويبقى شغّال 24/7)
1. روح لـ **railway.app** وسجّل حساب (بإيميلك أو بحساب GitHub).
2. اضغط **New Project** → **Deploy from GitHub repo** → اختر المستودع `cs-student-bot`.
3. بعد ما ينشئ المشروع، روح لتبويب **Variables** وأضف:
   - `BOT_TOKEN` = التوكن اللي أخذته من BotFather
   - `ADMIN_IDS` = آيدي حسابك (رقم). لو أكثر من أدمن، افصل بينهم بفاصلة: `111111,222222`
4. Railway يشغّل `python bot.py` تلقائياً (حسب `Procfile`). تأكد من تبويب **Deployments** إن الحالة **Success** وما فيه أخطاء.
5. روح لتلغرام وكلّم بوتك، اكتب `/myid` يرد عليك برقمك. انسخه وحطه في `ADMIN_IDS` بالخطوة اللي فوق إذا ما كنت حاطه، وأعد التشغيل (Redeploy).

> بديل Railway: **Render.com** بنفس الفكرة (New → Background Worker → اربط GitHub → نفس متغيرات البيئة)، أو أي سيرفر/VPS تشغّل عليه `python bot.py` داخل `screen` أو `systemd` حتى يفضل شغّال بعد ما تقفل الطرفية.

## 4) جرّب البوت
- اكتب `/start` في تلغرام.
- 📚 المواد → اختر فصل → اختر مادة → اختر قسم (فاضي أول مرة).
- بما إنك أدمن، يطلعلك زر 👑 **لوحة الإدارة** تحت.

## 5) إضافة محتوى (وأنت أدمن)
1. 👑 لوحة الإدارة → 📤 إضافة محتوى.
2. اختر الفصل ثم المادة ثم القسم.
3. ابعث الملف (رفع من جهازك أو **Forward** من أي شات آخر)، أو ابعث رابط يبدأ بـ `https://`.
4. اكتب الاسم اللي يبان للطلبة، أو أرسل `-` لاستخدام اسم الملف كما هو.
5. يظهر تلقائياً للطلبة تحت نفس المادة والقسم.

## 6) حذف أو نقل مادة
- 🗑️ حذف محتوى: فصل → مادة → قسم → اختر الملف واحذفه.
- ✏️ تعديل مادة: فصل → مادة → اختر الفصل الجديد، وتنتقل المادة له فوراً (في `courses.json`).
- 🌳 تحديث شجرة المواد: ابعث صورة جديدة فتستبدل القديمة.

## ملاحظات مهمة
- **الملفات تُخزَّن داخل تلغرام نفسه** (عبر `file_id`)، مو عندك ولا على GitHub — فما يوجد حد لحجم المشروع، بس كل ملف أقل من 50 ميجا تقريباً (حد تلغرام للبوتات).
- لو غيّرت `content.json` أو `courses.json` يدوياً من GitHub، تحتاج تعيد تشغيل الخدمة (Redeploy) على Railway حتى تنعكس التعديلات.
- لو حبيت تضيف طالب ثاني كأدمن، زيد آيديه في `ADMIN_IDS` وأعد التشغيل.
